Les données que Samdé conserve, et pourquoi

Samdé ne garde que ce qui est nécessaire pour tenir votre carnet :

  • Votre compte : votre numéro de téléphone (il sert d'identifiant pour vous connecter) et votre mot de passe. Le mot de passe n'est jamais lisible, ni par nous ni par personne : il est conservé sous forme transformée par notre hébergeur d'authentification.
  • Votre commerce : le nom du commerce, votre nom, votre numéro si vous le renseignez, et le message de rappel que vous avez choisi. Pourquoi : personnaliser votre carnet et vos rappels.
  • Votre carnet : vos clients (nom, numéro de téléphone, note), leurs crédits et leurs paiements (montant en FCFA, date, note) et la trace des rappels que vous avez ouverts (date, canal, montant, texte du message). Pourquoi : c'est le service lui-même, calculer ce que chaque client vous doit et le retrouver sur un autre téléphone.
  • Sur votre téléphone uniquement : le code de verrouillage (conservé sous forme transformée, jamais en clair) et votre connexion.
  • Si le suivi des plantages est activé dans votre version de Samdé : des rapports techniques anonymes (type d'erreur, version de l'application, modèle de téléphone et version du système). Ils ne contiennent ni nom, ni numéro, ni montant. Pourquoi : corriger les bugs.

Ce que Samdé ne collecte pas

  • Pas de publicité, pas de traceur, pas de statistiques sur ce que vous faites dans l'application.
  • Pas de position, pas de photos, pas de micro, pas de caméra.
  • Pas de lecture de vos contacts en arrière-plan : si vous choisissez d'importer un contact pour créer un client, seul le contact que vous sélectionnez est utilisé, et l'autorisation n'est demandée qu'à ce moment-là.
  • Pas de messages : Samdé n'envoie ni WhatsApp ni SMS à votre place.

Où sont vos données

Votre carnet est d'abord sur votre téléphone : Samdé fonctionne sans internet. Dès qu'il y a du réseau, une copie est envoyée sur nos serveurs, hébergés chez notre hébergeur de base de données, Supabase. Cette copie permet de retrouver votre carnet si vous changez de téléphone.

Les échanges entre l'application et les serveurs sont protégés (HTTPS). Chaque commerçant ne peut lire et modifier que ses propres données : c'est imposé par la base de données elle-même.

Sur le téléphone, le carnet est protégé par les protections du système (chaque application est isolée des autres) et par le verrouillage de votre téléphone. Samdé ne chiffre pas lui-même la base du carnet : si quelqu'un déverrouille votre téléphone, ou si votre téléphone est modifié de façon à contourner ses protections, ces données peuvent être lues. C'est pourquoi Samdé propose en plus son propre code de verrouillage.

Combien de temps

Vos données sont gardées tant que votre compte existe. Si vous supprimez votre compte, elles sont effacées de nos serveurs et de votre téléphone. Les copies de sauvegarde de notre hébergeur peuvent subsister temporairement après la suppression.

Qui peut voir vos données

Samdé ne vend pas vos données et ne les partage pas à des fins de publicité.

  • Vous. Personne d'autre, dans l'application.
  • Notre hébergeur, Supabase, qui fait fonctionner la base de données pour notre compte.
  • L'équipe de Samdé n'a pas besoin de lire votre carnet pour faire fonctionner le service.
  • WhatsApp ou votre application SMS, quand vous décidez d'envoyer un rappel : Samdé prépare le message, c'est vous qui appuyez sur « envoyer ». Ces services appliquent alors leurs propres règles.

Les données de vos clients

Les noms, numéros et montants de vos clients vous appartiennent : vous restez responsable de ces informations, et de leur bon usage. Samdé n'est que l'outil qui les conserve pour vous.

Informez vos clients que vous notez leur crédit dans un carnet, et n'utilisez leurs numéros que pour la relation commerciale (par exemple un rappel poli). À leur demande, corrigez ou supprimez leurs informations.

Vos droits, et comment les exercer

  • Voir et récupérer vos données : Profil > Exporter mes données (fichiers CSV et JSON).
  • Corriger : modifiez la fiche d'un client. Pour une erreur dans un crédit ou un paiement, on ne modifie pas la ligne : on l'annule, et l'historique reste honnête.
  • Supprimer : Profil > Supprimer mon compte. Tout est effacé, sur nos serveurs comme sur votre téléphone.
  • Toute autre demande (accès, opposition, réclamation) : écrivez-nous.

Sécurité

Vous pouvez protéger l'ouverture de Samdé par un code à 4 ou 6 chiffres, avec l'empreinte ou le visage si votre téléphone le permet. Le code n'est jamais conservé en clair. Choisissez un mot de passe que vous n'utilisez pas ailleurs, et ne le partagez pas.

Enfants

Samdé est destiné aux commerçants adultes. Il n'est pas conçu pour les enfants.

Changements

Si cette politique change de façon importante, nous vous le dirons dans l'application avant qu'elle s'applique. La date en haut de cette page indique la dernière mise à jour.
